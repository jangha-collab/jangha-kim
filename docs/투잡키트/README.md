## 워드 파일 다시 만들기

마크다운을 고친 뒤 아래를 실행한다. `docs/사업계획서/빌드/README.md`와 같은 방식이다.

```bash
export LC_ALL=C.UTF-8 LANG=C.UTF-8
for N in docs/투잡키트/1-제안서컨설팅/포트폴리오/*.md docs/투잡키트/3-전자책/전자책_원고_*.md; do
  pandoc "$N" -f gfm-strikeout -t docx --reference-doc="$PWD/docs/사업계획서/빌드/ref3.docx" -o "${N%.md}.docx"
  python3 docs/사업계획서/빌드/postdocx.py "${N%.md}.docx"
done
```

## 주의

- 포트폴리오와 전자책의 회사·숫자는 모두 가상이다. 고객 문서를 포트폴리오에 쓰지 않는다.
- 정부지원사업 신청서 대리 작성은 받지 않는다. 크몽 규정 위반이다.
- 본업 회사 문서는 클로드에 올리지 않고, 본업 업종·경쟁사 의뢰는 받지 않는다.
