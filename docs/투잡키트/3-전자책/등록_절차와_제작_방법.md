# 전자책 제작과 등록 절차

원고(`전자책_원고_결재통과형_제안서보고서_템플릿.md`)를 PDF·워드로 만들고 크몽과 유페이퍼에 올리는 순서다. 전체 소요 시간은 원고 교정을 빼면 4~6시간이다.

---

## 1. 제작

### 1.1 원고 교정 (2~3시간)

- 원고를 처음부터 끝까지 한 번 읽고 본인 경험으로 바꿀 곳을 고친다. 특히 머리말과 맺음말의 `[입력]`을 채운다.
- 클로드에 원고를 올리고 「오탈자, 중복 문장, 어색한 표현을 표로 찾아 달라」고 한 뒤 반영한다.
- 가상 업체명이 실존 회사와 겹치지 않는지 인터넷에서 검색한다.

### 1.2 워드·PDF 만들기 (30분)

이 저장소의 빌드 절차를 그대로 쓴다. 터미널에서:

```bash
export LC_ALL=C.UTF-8 LANG=C.UTF-8
N="docs/투잡키트/3-전자책/전자책_원고_결재통과형_제안서보고서_템플릿"
pandoc "$N.md" -f gfm-strikeout -t docx --reference-doc="$PWD/docs/사업계획서/빌드/ref3.docx" -o "$N.docx"
python3 docs/사업계획서/빌드/postdocx.py "$N.docx"
```

워드에서 열어 표지 한 장을 맨 앞에 넣고(표지 이미지 삽입), 「파일 → 내보내기 → PDF」로 저장한다. 쪽 번호가 있어야 유페이퍼 등록이 통과되므로 워드의 쪽 번호 삽입을 켠다.

구매자에게 줄 「템플릿 워드 파일」은 같은 docx에서 2부만 남기고 저장한 사본이다. 프롬프트 파일은 부록 C를 텍스트 파일(.txt)로 따로 저장한다.

### 1.3 표지 (30분)

캔바 무료 계정에서 「전자책 표지」 템플릿을 고르고 `판매페이지_원고.md` 6절의 문구로 바꾼다. 크몽 썸네일(가로형)과 유페이퍼 표지(세로형, 이미지 파일만 가능) 두 가지를 만든다.

## 2. 크몽 등록 (1시간)

1. 전문가 센터 → 서비스 등록 → 카테고리 「전자책·템플릿」 선택
2. 제목·한 줄 소개·상세 설명은 `판매페이지_원고.md` 1~4절
3. 가격 19,000원, 옵션 「내 문서 1건 30분 화상 점검 +50,000원」
4. 파일 첨부: PDF, 템플릿 docx, 프롬프트 txt를 하나의 zip으로
5. 미리보기 이미지: 5절의 발췌 3쪽을 이미지로 캡처해 올림
6. 수수료는 1순위 서비스와 같은 크몽 판매 수수료 정책을 따른다. 19,000원 기준 수수료는 약 4,100원(약 21.7%)으로 추정되며, 정확한 값은 판매 관리 화면의 수익금 계산기로 확인한다.
7. 심사(보통 1~3일) 통과 후 노출

## 3. 유페이퍼 등록 (1시간, 선택)

유페이퍼는 ISBN을 발급해 교보문고·예스24 같은 서점에 유통시켜 준다. 서점 유통은 수수료가 커서 수익보다 **「출간 저자」라는 신뢰 표시**가 목적이다. 1순위 상품 페이지의 「왜 저인가」에 「전자책 출간」 한 줄을 넣을 수 있다.

1. 유페이퍼 회원가입 → 판매자 등록(사업자등록증 또는 개인 정보)
2. 「전자책 만들기」 → PDF 업로드. 제목은 40자 이내, 표지는 이미지 파일, 쪽 번호가 겹치면 등록이 거부되므로 1.2절의 쪽 번호를 확인
3. ISBN 발급 신청(무료, 2~3일)
4. 가격 15,000원, 서점 유통 신청
5. 수수료와 정산 주기는 유페이퍼 공지사항에서 등록 시점에 확인한다. 이 문서 작성 시점에는 공개 자료로 확인하지 못했다.

## 4. 판매 후 운영

- **리뷰 요청.** 구매 확정 후 「도움이 된 템플릿 하나만 적어 주세요」라고 메시지. 첫 10개 리뷰까지가 노출을 결정한다.
- **1순위로 연결.** 구매자가 템플릿으로 쓴 문서를 점검받고 싶어 하면 옵션(50,000원) 또는 1순위 STANDARD로 안내한다. 전자책 맺음말에 안내 문구가 있다.
- **개정판.** 6개월마다 컨설팅에서 자주 나온 문서 유형을 템플릿으로 추가한다. 개정판은 크몽 기존 구매자에게 메시지로 다시 보낸다.
- **매출 기대.** 전자책은 월 5~15권(10~30만 원)이 현실적인 출발점이다. 1순위 매출을 대체하지 않고, 작업이 없는 달의 바닥 수익과 신뢰 표시 역할을 한다.
