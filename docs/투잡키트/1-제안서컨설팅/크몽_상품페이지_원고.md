# 크몽 상품 페이지 원고 (1순위: B2B 제안서·보고서 작성 컨설팅)

크몽 「전문가 등록 → 서비스 등록」 화면에 그대로 옮겨 적을 원고다. `[입력]`은 본인 경력으로 채운다. 카테고리는 「비즈니스 컨설팅 > 사업계획서·제안서」 또는 「문서·글쓰기 > 비즈니스 문서」 중 검색량이 많은 쪽을 고른다. 두 카테고리에 각각 등록해도 된다.

---

## 1. 서비스 제목 (30자 이내, 3안)

1. 결재 통과한 25년 경력자가 제안서·보고서 구조부터 잡아 드립니다
2. 중소기업 제안서·사업계획서·보고서, 심사자 관점으로 다시 씁니다
3. `[입력: 업종]` 현업 `[입력: N]`년, 제안서·보고서 초안부터 발표까지

검색 노출을 위해 제목에 「제안서」 「사업계획서」 「보고서」 중 두 개 이상을 넣는다.

## 2. 한 줄 소개 (검색 결과에 노출)

> 거래처 제안서, 투자·대출용 사업계획서, 사내 보고서를 결재자가 3분 안에 결론을 찾는 구조로 만듭니다. 48시간 안에 초안을 보여 드립니다.

## 3. 서비스 설명 (본문)

### 이런 분께 맞습니다

- 거래처에 낼 제안서를 써야 하는데 어디서 시작할지 모르는 중소기업 대표·영업 담당자
- 은행 대출이나 소액 투자 유치를 위해 사업계획서가 필요한 1인 사업자·초기 창업자
- 임원 보고용 기획서·실적 보고서를 짧은 시간에 완성해야 하는 팀장·실무자
- 민간 입찰 제안서를 처음 써 보는 회사

### 왜 저인가

- `[입력: 업종]`에서 `[입력: N]`년 근무하며 제안서 `[입력: N]`건을 직접 쓰고 수주·결재를 받았습니다.
- 쓰는 사람이 아니라 **읽고 결정하는 사람** 자리에 오래 있었습니다. 심사자가 어디서 멈추고 어디서 떨어뜨리는지 압니다.
- AI 도구를 작업 보조로 씁니다. 그래서 초안이 빠르고, 사람의 시간은 숫자 검증과 논리 점검에 씁니다.

### 작업 방식

1. 주문 후 질문지(15문항)를 보내 드립니다. 답변과 보유 자료를 보내 주시면 시작합니다.
2. **48시간 안에 목차와 1쪽 요약 초안**을 보여 드리고 방향을 맞춥니다. 이 단계에서 방향을 바꾸면 비용이 들지 않습니다.
3. 전체 초안 → 고객 확인 → 수정 → 납품(워드·한글·PDF 중 택 1, 슬라이드는 파워포인트).
4. 납품 후 등급별 수정 횟수 안에서 무료 수정합니다.

### 등급별 구성

| 구분        | STANDARD                        | DELUXE                              | PREMIUM                                                         |
| ----------- | ------------------------------- | ----------------------------------- | --------------------------------------------------------------- |
| 가격        | 250,000원                       | 450,000원                           | 800,000원                                                       |
| 분량        | 10쪽 이내                       | 20쪽 이내 + 요약 슬라이드 10장      | 20쪽 이상 + 슬라이드 + 재무표 정리                              |
| 적합한 문서 | 거래처 제안서, 사내 기획·보고서 | 사업계획서, 투자·대출용 문서        | 입찰 제안서, 투자 유치용 문서                                   |
| 포함        | 구조 설계, 초안, 교정 1회       | 구조 설계, 초안, 슬라이드, 교정 2회 | 구조 설계, 초안, 슬라이드, 재무표, 발표 리허설 피드백(화상 1회) |
| 납기        | 5일                             | 7일                                 | 10일                                                            |
| 수정        | 1회                             | 2회                                 | 3회                                                             |

추가 옵션: 급행(납기 절반) +50% / 영문 요약본(2쪽) +100,000원 / 추가 수정 1회 +50,000원

### 받지 않는 작업

- 정부지원사업(예비창업패키지 등) 신청서 대리 작성. 크몽 규정과 공고 규정에 어긋납니다.
- 논문·과제·자기소개서 대필
- 고객 자료 없이 처음부터 지어내는 문서. 사실이 아닌 실적·숫자는 쓰지 않습니다.
- `[입력: 본업 회사 업종]` 분야와 그 경쟁사의 문서. 본업과의 이해 충돌을 피하기 위해서입니다.

### 자료 보안

- 받은 자료는 작업에만 쓰고, 납품 30일 후 삭제합니다.
- AI 도구에 올린 자료도 작업 종료 후 대화를 삭제합니다.
- 포트폴리오에 고객 문서를 쓰지 않습니다. 상품 페이지의 예시는 모두 가상 업체 샘플입니다.

### 응답 시간

평일 21시 이후, 주말 10시 이후에 답변합니다. 문의는 언제든 남겨 주시면 당일 저녁 안에 답합니다.

## 4. 자주 묻는 질문

**Q. 자료가 거의 없어도 되나요?**
A. 질문지 답변만으로도 STANDARD는 가능합니다. 다만 실적 숫자, 가격표, 회사 소개 같은 기본 자료가 있으면 완성도가 올라갑니다.

**Q. 초안을 보고 마음에 안 들면요?**
A. 48시간 안에 보여 드리는 목차·요약 단계에서 방향을 다시 잡습니다. 이 단계의 방향 변경은 수정 횟수에 들어가지 않습니다.

**Q. 한글(HWP)로 받을 수 있나요?**
A. 네. 워드·한글·PDF 중 하나를 고르시면 됩니다.

**Q. 발표도 도와주시나요?**
A. PREMIUM에 발표 리허설 피드백(화상 1회, 40분)이 포함됩니다. 다른 등급은 옵션으로 추가할 수 있습니다.

**Q. 정부지원사업 사업계획서도 되나요?**
A. 받지 않습니다. 신청자가 직접 작성해야 하는 서류이고 크몽 규정에도 어긋납니다. 민간 투자·대출용 사업계획서는 가능합니다.

## 5. 취소·환불 규정 (크몽 표준 문구에 맞춰 입력)

- 작업 시작 전: 전액 환불
- 질문지 발송 후 자료 수령 전: 전액 환불
- 목차·요약 초안 전달 후: 결제 금액의 50% 환불
- 전체 초안 전달 후: 환불 불가 (수정 횟수 안에서 수정)

## 6. 포트폴리오 등록

`포트폴리오/` 폴더의 가상 샘플 3건을 PDF로 변환해 올린다. 각 샘플 표지에 「가상 업체 샘플」 표기를 유지한다. 썸네일 문구 예: 「STANDARD 예시 — 식자재 공급 제안서 10쪽」.

## 7. 첫 달 운영 메모

- 첫 5건까지 STANDARD 200,000원으로 등록하고, 리뷰 5개를 받으면 250,000원으로 올린다.
- 리뷰 요청 문구는 `고객응대_템플릿.md`의 6번을 쓴다.
