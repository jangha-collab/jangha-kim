## 1. 요약

㈜대양정밀 구내식당의 식자재 공급을 현재 3개 업체에서 ㈜한빛푸드시스템 1개로 통합하면 연간 식자재비 2,700만 원(6.2%)을 줄일 수 있다. 검수 시간은 하루 75분에서 25분으로, 재고 폐기율은 4.1%에서 2.7%로 내려간다. 도입에는 계약 후 6주가 걸리고, 그중 4주는 기존 업체와 병행하는 시범 운영이다.

절감의 근거는 세 가지다. 첫째, 농산물·축산물·공산품을 한 곳에서 사면 월 매입액이 3,000만 원을 넘어 통합 할인 2~3%가 적용된다. 둘째, 새벽 1회 배송으로 재고 보유 일수가 3일에서 1.5일로 줄어 폐기가 감소한다. 셋째, 세척·절단을 자사 전처리 센터가 맡아 조리원의 오전 전처리 시간이 하루 4시간에서 1시간으로 준다.

| 구분      | 제안 요약                                                   |
| --------- | ----------------------------------------------------------- |
| 공급 범위 | 농산·축산·수산·공산품·전처리 식재 5개 품목군, 약 420개 품목 |
| 배송      | 주 6일 새벽 1회(05:30~06:30), 냉장·냉동 분리 차량           |
| 품질      | 3단계 입고 검수, 부적합품 당일 교환, 월간 품질 보고서       |
| 가격      | 고정단가·시세연동·월고정 3방식 혼합, 월 매입액 할인 2~3%    |
| 계약 기간 | 1년, 상호 이의 없으면 1년 단위 자동 연장                    |
| 기대 효과 | 연 2,700만 원 절감, 검수 시간 1일 50분 단축                 |

## 2. 고객 현황과 과제

### 2.1 현황

㈜대양정밀 구내식당은 1일 600명(중식 480명, 석식 120명)에게 식사를 제공한다. 월 운영일은 22일, 월 식수는 약 13,200식이다. 1식 식자재 원가는 2,750원으로, 연간 식자재비는 약 4억 3,560만 원이다.

| 항목            | 수치               | 출처                        |
| --------------- | ------------------ | --------------------------- |
| 1일 식수        | 600명              | 총무팀 2026년 8월 식수 집계 |
| 월 운영일       | 22일               | 생산 캘린더                 |
| 연 식수         | 158,400식          | 13,200식 × 12개월           |
| 1식 식자재 원가 | 2,750원            | 2026년 상반기 평균          |
| 연 식자재비     | 4억 3,560만 원     | 158,400식 × 2,750원         |
| 현재 공급업체   | 3곳                | 농산 1, 축수산 1, 공산품 1  |
| 조리 인력       | 영양사 1, 조리원 6 | 총무팀 자료                 |

### 2.2 과제

2026년 9월 15일 현장 방문과 영양사 면담에서 다섯 가지 과제를 확인했다. 모두 공급업체가 셋으로 나뉜 구조에서 비롯된다.

| 번호 | 과제             | 현재 상태                              | 영향                             |
| ---- | ---------------- | -------------------------------------- | -------------------------------- |

| 2    | 농산물 단가 변동 | 월별 단가 편차 ±18%                    | 월 식자재비 예측 불가            |

| 5    | 위생 서류 분산   | 업체별 원산지·검사 서류 따로 수령      | 분기 위생 점검 때 자료 취합 지연 |

## 3. 제안 내용

### 3.1 공급 품목

5개 품목군 약 420개 품목을 공급한다. 현재 3개 업체가 납품하는 품목 387개 중 381개(98.4%)가 당사 취급 품목이며, 나머지 6개는 동급 대체품을 제시한다.

| 품목군      | 주요 품목                              | 매입 비중 | 규격·원산지 기준                 |
| ----------- | -------------------------------------- | --------- | -------------------------------- |
| 농산물      | 쌀, 양파, 대파, 배추, 감자, 당근, 과일 | 32%       | 국내산 우선, 상품(上) 등급       |
| 축산물      | 돼지 앞다리·삼겹, 닭 정육, 소 불고기용 | 28%       | 국내산, 도축 후 3일 이내 입고    |
| 수산물      | 고등어, 오징어, 동태, 어묵             | 9%        | 냉동 −18℃ 이하 유지              |
| 공산품·양념 | 식용유, 간장, 고추장, 밀가루, 김치     | 21%       | 유통기한 잔여 60% 이상 입고      |
| 전처리 식재 | 세척 채소, 절단 채소, 손질 육류        | 10%       | 자사 전처리 센터 생산, 당일 출고 |

### 3.2 배송

주 6일 새벽 1회 배송을 기본으로 한다. 05:30~06:30 사이에 도착하므로 조리원 출근(06:30) 직후 검수와 조리를 바로 시작할 수 있다. 긴급 추가 배송은 주문 후 2시간 이내이며 월 2회까지 무상이다.

| 구분        | 시간           | 차량                  | 온도 관리                     |
| ----------- | -------------- | --------------------- | ----------------------------- |
| 정기 배송   | 05:30~06:30    | 냉장·냉동 분리 2칸 차 | 칸별 온도기록지 매회 제출     |
| 긴급 배송   | 주문 후 2시간  | 소형 냉장차           | 동일                          |
| 전처리 식재 | 정기 배송 동승 | 냉장칸(0~5℃)          | 출고~입고 온도 이력 전산 보관 |

배송 기사는 전담 1명과 예비 1명을 둔다. 전담 기사가 입고 위치, 보관 순서, 담당 조리원을 숙지하므로 하역 시간이 짧아진다.

### 3.3 품질관리

입고 검수를 3단계로 나눠 부적합품이 조리에 들어가지 않게 한다. 당사가 출고 전에 1차 검수를 마치고 사진과 온도 기록을 전송하므로, 귀사 영양사는 2차 검수를 현물 대조만으로 끝낼 수 있다.

| 단계 | 시점    | 주체           | 내용                                |
| ---- | ------- | -------------- | ----------------------------------- |
| 1차  | 출고 전 | 당사 품질 담당 | 규격·신선도·온도 확인, 사진 전송    |
| 2차  | 입고 시 | 귀사 영양사    | 전송 자료와 현물 대조, 서명         |
| 3차  | 주 1회  | 당사 품질 담당 | 현장 방문, 보관 상태·잔여 재고 점검 |

부적합품은 입고 당일 교환한다. 교환이 어려우면 동급 대체품을 공급하고 차액은 당사가 부담한다. 반품률과 교환 내역은 월간 품질 보고서에 담아 매월 5일 전달한다.

위생 서류는 품목별 원산지 증명, 축산물 등급 판정 결과, 공산품 검사 성적서를 매월 1회 한 묶음으로 제공한다. 전처리 식재는 2024년 HACCP 인증을 받은 자사 센터에서 생산한다.

### 3.4 가격 구조

단가는 품목 특성에 따라 세 방식으로 정한다. 변동이 큰 농산물은 시세에 연동하되 할인율을 고정해 투명성을 확보하고, 나머지는 고정해 월 식자재비를 예측할 수 있게 한다.

| 방식          | 적용 품목군   | 단가 기준                     | 조정 주기 |
| ------------- | ------------- | ----------------------------- | --------- |
| 고정단가      | 공산품·양념   | 계약 단가표                   | 분기      |
| 시세연동      | 농산물·수산물 | 주간 도매시장 평균 시세 − 3%  | 주 1회    |
| 월고정        | 축산물        | 전월 평균 시세 기준 당월 고정 | 월 1회    |
| 전처리 가공비 | 전처리 식재   | 원물 단가 + kg당 가공비 380원 | 분기      |

월 매입액에 따라 통합 할인을 추가한다. 귀사의 월 예상 매입액은 3,630만 원이므로 3% 구간에 해당한다.

대표 품목 10개의 단가를 현재 납품가와 비교하면 다음과 같다. 현재 납품가는 귀사가 제공한 2026년 8월 거래명세서를 기준으로 했다.

## 4. 기대 효과

연간 2,700만 원의 식자재비 절감이 핵심 효과다. 금액 근거는 통합 할인, 폐기 감소, 전처리 대체 세 항목이며 각각 독립적으로 계산했다.

| 효과 항목                   | 현재              | 도입 후           | 연간 효과       |
| --------------------------- | ----------------- | ----------------- | --------------- |
| 식자재 단가(통합 할인 포함) | 연 4억 3,560만 원 | 연 4억 2,310만 원 | 1,250만 원 절감 |
| 재고 폐기율                 | 4.1%              | 2.7%              | 620만 원 절감   |
| 전처리 인력 시간            | 1일 4시간         | 1일 1시간         | 830만 원 상당   |
| 입고 검수 시간              | 1일 75분          | 1일 25분          | 연 220시간 확보 |
| 세금계산서·서류             | 월 3건, 6시간     | 월 1건, 2시간     | 연 48시간 확보  |

전처리 인력 시간 830만 원은 조리원 시급 환산액(10,500원) × 절감 3시간 × 운영일 264일로 계산했다. 인력을 줄이는 것이 아니라 조리 준비와 석식 품질 관리에 시간을 돌리는 효과다.

금액으로 환산하지 않은 효과도 있다. 월 식자재비 편차가 ±18%에서 ±6% 이내로 줄어 예산 관리가 쉬워지고, 위생 점검 서류를 한 번에 받아 분기 점검 준비 시간이 짧아진다.

## 5. 도입 일정

계약일부터 6주 안에 전환을 마친다. 4주간의 시범 운영 동안 기존 업체 계약을 유지하므로 급식 중단 위험이 없다.

| 주차 | 단계           | 주요 활동                                           | 귀사 협조 사항           |
| ---- | -------------- | --------------------------------------------------- | ------------------------ |
| 1주  | 계약·품목 확정 | 계약 체결, 420개 품목 단가표 확정, 입고 동선 확인   | 식단표 1개월분 공유      |
| 2주  | 시범 운영 1    | 농산물·공산품 먼저 납품, 기존 업체 병행             | 2차 검수 서명            |
| 3주  | 시범 운영 2    | 축산·수산·전처리 식재 추가, 단가 대조 명세 제공     | 조리원 전처리 식재 평가  |
| 4주  | 시범 운영 3    | 전 품목 납품, 긴급 배송 모의 시험 1회               | 만족도 설문(조리원 7명)  |
| 5주  | 시범 운영 4    | 시범 결과 보고, 단가·규격 조정                      | 조정안 승인              |
| 6주  | 전환 완료      | 기존 업체 종료, 단독 공급 시작, 월간 보고 체계 가동 | 기존 업체 계약 종료 통보 |

시범 운영 중 품목별 단가 차이가 제안서 수치보다 1%p 이상 불리하면 귀사는 위약 없이 계약을 해지할 수 있다. 이 조건은 계약서 특약에 명시한다.

## 6. 회사 소개

㈜한빛푸드시스템은 2015년 설립한 급식 식자재 유통 전문 회사다. 직원 25명, 2025년 매출 48억 원이며 수도권 남부에 물류센터와 전처리 센터를 운영한다. 거래처 34곳 중 19곳이 귀사와 같은 제조업체 구내식당이다.

1일 식수 500명 이상 제조업 구내식당 6곳과 평균 4.2년째 거래하고 있다. 가장 오래된 거래처는 2016년부터 10년째다. 해당 거래처의 담당자 연락처는 귀사 요청 시 동의를 받아 제공한다.

## 7. 담당자

제안 검토와 시범 운영 기간 동안 아래 3명이 귀사를 전담한다. 영업 담당이 창구이며, 품질·배송 담당은 현장 문의에 직접 응대한다.

| 역할      | 성명·직책   | 연락처        | 담당 업무                         |
| --------- | ----------- | ------------- | --------------------------------- |
| 영업 담당 | 김도윤 팀장 | 010-0000-1234 | 계약, 단가, 시범 운영 총괄        |
| 품질 담당 | 박세린 과장 | 010-0000-2345 | 검수 기준, 부적합 처리, 월간 보고 |
| 배송 담당 | 이준호 반장 | 010-0000-3456 | 배송 시간, 긴급 배송, 하역        |

문의는 평일 06:00~18:00에 받는다. 긴급 배송 요청은 배송 담당에게 전화로 하면 접수 즉시 출고 여부를 회신한다.
