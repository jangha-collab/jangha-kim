# 구글을 통해 돈을 버는 투잡 추가 조사

**50대 직장인 조건(하루 1~2시간, 자본·재고 없음, 영업·마케팅 없음, 월 매출 300만 원, 클로드 활용)으로 구글 기반 수익원 11가지를 검토한 결과**

- 작성일: 2026년 10월 8일
- 버전: v1.0
- 관련 문서: `2026-10_클로드활용_직장인투잡_사업계획서.md` (본 계획), `docs/투잡키트/` (실행 자료)

## 0. 결론

**구글 기반으로 월 300만 원을 혼자 만드는 투잡은 조건에 맞는 것이 없다.** 구글이 직접 돈을 주는 방식(애드센스, 유튜브, 플레이 북스)은 모두 「많은 사람이 봐야 돈이 되는」 구조라 사실상 마케팅과 긴 축적 기간이 필요하다. 반면 **구글 도구를 써서 남의 일을 해 주는 방식**은 플랫폼이 수요를 가져오고 클로드가 작업을 돕기 때문에 조건에 맞는다.

| 순위 | 구글 기반 투잡                                   | 역할                                        | 월 기대 매출          | 판정                          |
| ---- | ------------------------------------------------ | ------------------------------------------- | --------------------- | ----------------------------- |
| G1   | 구글 시트·앱스 스크립트 업무 자동화 대행 (크몽)  | 본 계획 1순위의 보조 상품. 같은 고객층      | 50~100만 원           | **추가 권장**                 |
| G2   | 구글 플레이 북스 전자책 출판                     | 본 계획 3순위 전자책의 추가 유통 채널       | 5~15만 원             | 추가 권장 (1시간이면 등록)    |
| G3   | 구글 시트 템플릿 판매 (크몽)                     | 3순위 디지털 상품 확장                      | 5~20만 원             | 추가 권장                     |
| G4   | 구글 검색 품질 평가자 (TELUS Digital·Appen 외주) | 시급형 안정 수익. 클로드 활용 불가          | 90~170만 원 (모집 시) | 조건부. 한국 모집이 열릴 때만 |
| G5   | 애드센스 블로그 (블로거·티스토리·워드프레스)     | 12개월 이상 걸리는 장기 자산                | 1년 차 10~50만 원     | 장기 보조. 300만 원 단독 불가 |
| G6   | 유튜브 (롱폼·쇼츠)                               | 2027년부터 조건 2배 상향                    | 불확실                | 제외                          |
| G7   | 구글 비즈니스 프로필 등록·관리 대행              | 등록은 무료라 사기 논란, 관리형은 영업 필요 | -                     | 제외                          |
| G8   | 구글 애즈(광고) 운영 대행                        | 광고비 책임·영업 필요                       | -                     | 제외                          |
| G9   | 구글 플레이 앱 개발 + 애드몹                     | 마케팅·유지보수 필요, 수익 불확실           | -                     | 제외                          |
| G10  | 구글 워크스페이스 마켓플레이스 부가기능          | 개발·마케팅 필요                            | -                     | 제외                          |
| G11  | 구글 오피니언 리워드, 로컬 가이드                | 푼돈 또는 무보수                            | 월 1만 원 미만        | 제외                          |

**권장 조합.** 본 계획의 1순위(제안서 컨설팅)와 3순위(전자책)에 G1·G2·G3을 얹는다. 모두 같은 크몽 계정, 같은 중소기업 고객, 같은 클로드 작업 방식이라 추가 영업이 없다. G1이 자리 잡으면 월 매출은 본 계획 300만 원에 50~100만 원이 더해진다. G4는 한국 거주자 모집이 열렸을 때 지원해 두고, 선발되면 작업이 없는 달을 메우는 시급형 수익으로 쓴다.

### 이 문서의 근거 수준 (읽기 전에)

- **애드센스 수익.** 한국 RPM(1,000회 노출당 수익) 공식 통계는 없다. 블로그 추정치(RPM 1.5~4달러)와 카테고리별 편차를 기준으로 계산했다.
- **유튜브 조건.** 2026년 8월 발표된 2027년 2월 1일 기준 상향(시청 8,000시간 또는 쇼츠 2,000만 회)은 언론 보도 기준이다. 적용 전 공식 정책 페이지로 확인해야 한다.
- **품질 평가자.** 시급 15달러는 TELUS International 재게시 공고 기준이며 현재 한국 모집 여부는 확인하지 못했다. Appen은 시급 9~18달러 범위로 보도된다.
- **플레이 북스 배분율.** 70% 배분 국가 목록에 한국이 명시되어 있지 않다. 한국 판매분은 52~70% 사이로 보고 파트너 센터 「유효 가격」 표에서 직접 확인해야 한다.
- **앱스 스크립트 단가.** 크몽 카테고리 안내(매크로·앱스 스크립트 8~25만 원)와 실제 상품 가격(5~29만 원)을 근거로 했다.

## 1. 구글이 직접 돈을 주는 방식: 왜 조건에 안 맞나

### 1.1 애드센스 블로그 (G5)

- **구조.** 블로그에 광고를 붙이고 방문자가 보거나 클릭하면 구글이 돈을 준다. 글만 쓰면 되고 자본이 없어 「영업 없는 투잡」으로 자주 소개된다.
- **숫자.** 수익 = 월 조회수 ÷ 1,000 × RPM. 한국 생활 정보 블로그의 RPM을 1.5~4달러로 보면 월 300만 원(약 2,140달러)에는 **월 54만~143만 조회(하루 1.8만~4.8만)**가 필요하다. 금융·보험·법률처럼 단가가 높은 주제는 더 적은 조회로 가능하지만, 그 주제는 경쟁이 가장 심하다.
- **시간.** 하루 1~2시간이면 글 1편이 한계다. 검색 유입이 생기려면 보통 글 100~200편과 6~12개월이 걸린다. 최근에는 검색 결과에 AI 요약이 먼저 나와 블로그 유입이 줄어드는 흐름도 있다.
- **판정.** 300만 원 목표의 수단으로는 부적합하다. 다만 **본 계획 1순위의 전문성(제안서·보고서 쓰는 법)을 블로그에 쌓으면** 1년 뒤 월 10~50만 원의 바닥 수익과 「검색되는 전문가」라는 신뢰 표시가 된다. 클로드로 초안을 만들고 본인 경험을 더하는 방식이면 글 1편에 40분이다. 할 거면 1순위 운영이 안정된 3개월 차 이후에 주 2편으로 시작한다.

### 1.2 유튜브 (G6)

- **조건(2026년 현재).** 구독자 1,000명 + 최근 12개월 시청 4,000시간 또는 최근 90일 쇼츠 조회 1,000만 회. **2027년 2월 1일부터 신규 가입자는 8,000시간 또는 쇼츠 2,000만 회**로 두 배가 된다.
- **쇼츠 단가.** 쇼츠 RPM 추정치는 0.03~0.10달러다. 100만 회를 모아도 수만 원이다.
- **시간.** 영상 1편에 촬영·편집 3시간 이상. 하루 1~2시간으로는 주 2편이 한계이고, 얼굴·목소리 노출이 필요하다.
- **판정.** 제외. 다만 1순위 고객용 설명 영상(「제안서 작성 3원칙」 같은 5분 영상)을 유튜브에 올려 상품 페이지에 링크하는 것은 수익이 아니라 신뢰 용도로 쓸 수 있다.

### 1.3 구글 플레이 북스 (G2)

- **구조.** 파트너 센터에 전자책을 올리면 구글 플레이 스토어에서 판매되고 정가 기준으로 배분받는다. 등록비는 없다.
- **배분율.** 2019년 개정 약관을 수락한 파트너는 대부분 국가에서 70%지만, 70% 국가 목록에 한국이 명시돼 있지 않아 52~70% 사이로 봐야 한다.
- **판정.** 본 계획 3순위 전자책을 **추가로 올리는 채널**로는 좋다. 크몽·유페이퍼용 PDF와 표지를 그대로 쓰므로 등록에 1시간이면 되고, 판매는 월 몇 권이라도 비용이 없다. 수익보다는 「구글 플레이에서 검색되는 저자」라는 표시가 목적이다.

### 1.4 플레이 앱, 워크스페이스 부가기능, 비즈니스 프로필, 애즈 대행 (G7~G10)

- **플레이 앱 + 애드몹(G9).** 클로드로 간단한 앱을 만들 수는 있지만 개발자 등록비(25달러), 심사, 업데이트 대응, 그리고 다운로드를 만들기 위한 마케팅이 필요하다. 광고 수익은 하루 수천 명이 써야 월 수십만 원이다.
- **워크스페이스 마켓플레이스 부가기능(G10).** 구글 시트·문서에 붙는 확장 프로그램을 팔 수 있지만 개발·보안 심사·마케팅이 필요하다. 1~2시간 투잡 범위를 넘는다.
- **비즈니스 프로필 대행(G7).** 구글 지도 등록은 사업주가 직접 무료로 할 수 있어 등록 대행은 사기 논란이 있다. 월 관리형은 소상공인을 직접 찾아다니는 영업이 필요하다.
- **애즈 대행(G8).** 남의 광고비를 운용하는 일이라 성과 책임이 크고, 고객 확보 자체가 영업이다.
- **오피니언 리워드, 로컬 가이드(G11).** 설문 하나에 몇백 원, 로컬 가이드는 포인트만 준다.

## 2. 구글 도구로 남의 일을 해 주는 방식: 조건에 맞는 것

### 2.1 G1. 구글 시트·앱스 스크립트 업무 자동화 대행

**무엇인가.** 중소기업·1인 사업자가 구글 시트로 하는 반복 업무(견적서 자동 생성, 구글 폼 접수를 시트로 모아 메일 발송, 재고·매출 집계 대시보드, 일정 알림)를 앱스 스크립트로 자동화해 준다. 크몽 「엑셀·스프레드시트」 카테고리에 수요가 있고 구매자가 검색해서 찾아온다.

**왜 조건에 맞나.**

| 조건        | 적합성                                                                                              |
| ----------- | --------------------------------------------------------------------------------------------------- |
| 자본·재고   | 구글 계정만 있으면 된다. 앱스 스크립트는 무료                                                       |
| 영업·마케팅 | 크몽 검색 유입. 1순위와 같은 계정에 상품만 추가                                                     |
| 시간        | 건당 2~6시간, 납기 3~5일. 1순위 작업이 비는 주에 채운다                                             |
| 클로드 활용 | 코드 생성은 클로드가 가장 잘하는 일이다. 요구사항을 한국어로 설명하면 스크립트와 설치 설명을 만든다 |
| 50대 경력   | 「어떤 업무를 자동화해야 효과가 있는지」를 아는 것이 핵심이다. 코딩보다 업무 흐름 이해가 가치다     |

**정직하게 짚을 점.** 클로드가 코드를 써 주더라도 고객 시트에서 안 돌아갈 때 원인을 찾는 디버깅은 본인이 해야 한다. 처음 3~5건은 계획 시간의 2배가 든다. 비개발자라면 첫 달에 본인 업무용 시트 자동화 2~3개를 클로드와 만들어 보고 시작한다.

**상품 구성 (크몽 시세 기준).**

| 등급     | 가격      | 범위                                                                    | 납기 | 작업 시간 |
| -------- | --------- | ----------------------------------------------------------------------- | ---- | --------- |
| STANDARD | 50,000원  | 시트 1개, 기능 1개 (예: 버튼 누르면 견적서 PDF 생성·메일 발송)          | 3일  | 2시간     |
| DELUXE   | 150,000원 | 시트 여러 개 연동 + 구글 폼·메일·캘린더 연결, 기능 3개 이내             | 5일  | 4시간     |
| PREMIUM  | 300,000원 | 폼 접수 → 시트 집계 → 문서 자동 생성 → 대시보드까지 업무 흐름 하나 전체 | 7일  | 6~8시간   |

모든 등급에 스크립트 원본, 설치 설명서, 수정 1회를 포함한다. 유지보수는 월 30,000원 옵션.

**작업 흐름과 클로드 역할.**

| 단계 | 사람                                                    | 클로드                                           |
| ---- | ------------------------------------------------------- | ------------------------------------------------ |
| 접수 | 고객 시트 사본(개인정보 가린 것)과 원하는 동작을 받는다 | 요구사항을 기능 목록과 확인 질문으로 정리        |
| 설계 | 어떤 시트·열을 쓰는지 확정                              | 시트 구조 제안, 예외 상황(빈 칸, 중복) 목록      |
| 구현 | 클로드가 만든 코드를 사본 시트에 붙여 실행              | 앱스 스크립트 코드 작성, 오류 메시지 해석과 수정 |
| 시험 | 실제 데이터 모양으로 5가지 경우 시험                    | 시험 사례 생성                                   |
| 납품 | 고객 시트에 설치, 화면 녹화 설명 3분                    | 설치 설명서와 사용법 작성                        |

**수익 전망.** 월 STANDARD 4건 + DELUXE 2건 + PREMIUM 1건 = 80만 원, 작업 시간 약 22시간. 1순위(54시간)와 합치면 월 76시간으로 하루 2.5시간이 되므로, **1순위가 월 8건을 채우는 달에는 G1을 줄인다.** G1은 1순위 주문이 비는 달을 메우는 용도이며, 둘을 합쳐 월 300~380만 원 범위에서 시간 상한(60시간)으로 조절한다.

**리스크.**

| 리스크                           | 대응                                                                      |
| -------------------------------- | ------------------------------------------------------------------------- |
| 고객 시트 권한·개인정보 노출     | 반드시 가린 사본으로 작업. 고객 시트에는 설치만 하고 데이터는 받지 않는다 |
| 구글 정책·API 변경으로 동작 중단 | 납품 후 30일 무상 수정, 이후 유지보수 옵션                                |
| 요구사항이 계속 늘어남           | 기능 개수를 등급에 명시, 추가 기능은 STANDARD 단위로 추가 주문            |
| 디버깅에 시간이 과다             | 첫 달 연습 3건, 클로드에 오류 메시지 전문과 시트 구조를 함께 보내는 습관  |

### 2.2 G3. 구글 시트 템플릿 판매

3순위 전자책과 같은 방식의 디지털 상품이다. 1순위·G1 작업에서 반복되는 시트를 템플릿으로 만들어 크몽에 1~3만 원에 올린다. 후보: 제안서 원가·견적 산출 시트, 입찰 용역비 산출표, 3개년 재무 계획 시트(사업계획서용), 영업 파이프라인 관리 시트. 전자책 묶음에 「부록 시트 4종」으로 넣어 전자책 가격을 올리는 방법도 있다. 제작은 건당 2~3시간, 판매는 월 5~20만 원 수준으로 본다.

### 2.3 G4. 구글 검색 품질 평가자

- **무엇인가.** 구글이 외주 업체(TELUS Digital, Appen 등)를 통해 고용하는 재택 평가자. 검색 결과가 질문에 맞는지 공개된 지침에 따라 채점한다.
- **조건.** 시급 약 15달러(약 2만 원), 주 10~20시간, 근무 시간 자율. 영업·자본이 없고 50대도 지원할 수 있다. 월 90~170만 원 수준이 가능하다.
- **안 맞는 점.** 한국 거주자 모집은 불규칙하고 자격 시험 탈락률이 높다. 업무량이 주마다 달라지고 지급 지연 후기도 있다. **AI 도구 사용이 금지되므로 클로드를 쓸 수 없다.** 300만 원을 혼자 만들 수 없다.
- **판정.** 조건부 보조. 업체 공식 채용 페이지에서 「Korean」 「South Korea」 공고를 월 1회 확인하고, 열리면 지원해 둔다. 지원비·교육비를 요구하면 사기다.
