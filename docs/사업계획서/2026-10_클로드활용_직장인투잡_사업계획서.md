# 클로드 활용 직장인 투잡 추천 및 사업계획서

**50대 직장인이 하루 1~2시간, 자본·재고·영업 없이 월 매출 300만 원을 만드는 「B2B 제안서·보고서 작성 컨설팅」**

- 작성 대상: 50대 남성 직장인 (하루 가용 시간 1~2시간, 자본금·재고 없음, 영업·마케팅 활동 없이, 월 매출 300만 원 목표)
- 작성일: 2026년 10월 8일
- 버전: v1.0 (검토용 초안)

> **이 문서의 사용법.** 1~2장은 조건에 맞는 투잡 후보를 비교하고 하나를 고르는 과정이다. 3장부터가 선택한 투잡의 사업계획서다. 바로 시작하려면 6장 「첫 30일 실행 체크리스트」부터 보면 된다. `[입력]`으로 표시한 곳은 본인 경력에 맞게 채운다.

## 0. 요약 (Executive Summary)

**추천 1순위: 크몽 입점형 「B2B 제안서·보고서·기획문서 작성 컨설팅」.** 중소기업과 1인 사업자가 거래처 제안서, 투자·대출용 사업계획서, 사내 보고서, 입찰 제안서 초안을 맡기는 수요를 크몽·숨고 같은 재능 플랫폼이 가져다준다. 판매자는 프로필과 상품 페이지를 한 번 만들어 두고 주문이 들어오면 클로드로 초안을 만들어 경력으로 다듬는다. 50대 직장인의 20~30년 보고서·제안서 경험이 그대로 상품이 되고, 클로드가 작성 시간을 3분의 1로 줄여 하루 1~2시간 안에 처리할 수 있다.

**왜 이 일인가.** 네 가지 조건을 모두 만족하는 투잡은 많지 않다.

| 조건               | 이 일이 맞는 이유                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| 자본·재고 없음     | 노트북과 클로드 구독(월 3만 원 안팎)이 전부. 사업자등록도 무료                                          |
| 영업·마케팅 없음   | 크몽은 구매자가 검색해서 찾아오는 구조. 상품 페이지와 리뷰가 영업을 대신한다. 광고·SNS·전화 영업이 없다 |
| 하루 1~2시간       | 1건당 4~14시간을 며칠에 나눠 처리. 납기를 5~7일로 잡으면 퇴근 후 시간으로 충분하다                      |
| 월 매출 300만 원   | 단가 25~80만 원이므로 월 8건 안팎이면 도달. 건당 단가가 높아 많은 고객을 상대할 필요가 없다             |
| 50대 직장인의 강점 | 젊은 프리랜서가 갖지 못한 「결재받아 본 경험」, 업계 용어, 의사결정자 관점이 차별점이 된다              |

**목표 숫자 (안정기, 입점 7개월 차 이후).**

| 항목            | 월 기준                                            |
| --------------- | -------------------------------------------------- |
| 매출(결제 금액) | 315만 원 (STANDARD 4건 + DELUXE 3건 + PREMIUM 1건) |
| 플랫폼 수수료   | 약 65만 원 (판매가의 약 20~22%)                    |
| 고정비          | 약 5만 원 (클로드 구독, 통신)                      |
| 세전 순수익     | 약 245만 원                                        |
| 작업 시간       | 약 54시간 (하루 평균 1.8시간)                      |

**도달 일정.** 1~2개월 차는 프로필·포트폴리오를 만들고 첫 리뷰를 모으는 기간이라 매출 30~60만 원이다. 3~4개월 차 100~150만 원, 5~6개월 차 200~250만 원, 7개월 차 이후 300만 원 안팎을 목표로 한다. 플랫폼 투잡은 리뷰가 쌓일 때까지 주문이 적다는 점을 처음부터 계산에 넣어야 한다.

**후보 비교 요약.** 조건에 맞춰 검토한 투잡 8가지 중 상위 3가지는 다음과 같다. 자세한 비교는 2장.

| 순위 | 투잡                                   | 단가       | 300만 원에 필요한 월 건수 | 한 줄 평가                                                       |
| ---- | -------------------------------------- | ---------- | ------------------------- | ---------------------------------------------------------------- |
| 1    | B2B 제안서·보고서 작성 컨설팅          | 25~80만 원 | 8건 안팎                  | 경력이 곧 상품. 단가가 높아 시간 조건에 맞는다                   |
| 2    | 경력직(40~50대) 이력서·경력기술서 첨삭 | 5~15만 원  | 25~40건                   | 수요가 꾸준하지만 건수가 많아 하루 2시간을 넘기기 쉽다           |
| 3    | 제안서·보고서 템플릿 전자책 판매       | 1~3만 원   | 100건 이상                | 자동 수익이지만 노출을 위한 마케팅이 필요. 1순위의 부산물로 병행 |

### 이 문서의 근거 수준 (읽기 전에)

- **플랫폼 수수료.** 크몽 공식 안내(2024년 7월 개편)의 계산 예시를 기준으로 했다. 70만 원 이하 구간 서비스 이용료 16.4%에 결제망 이용료 3.3%, 수수료에 붙는 부가세 10%를 합치면 판매가의 약 21.7%다. 금액이 커질수록 구간별 요율이 낮아진다. 2026년 현재 구간표는 크몽 판매자 화면의 「수익금 계산기」로 재확인해야 한다.
- **단가.** 숨고가 공개한 사업계획서 작성 평균 비용(30만 원, 10~50만 원 범위)과 크몽 이력서 교정 가격 안내(평균 5만 원, 최고 15만 원 이상)를 근거로 삼았다. 개별 판매자 가격은 확인하지 못했으므로 이 문서의 가격표는 당사 제안이다.
- **매출 도달 일정.** 플랫폼 신규 판매자가 리뷰를 쌓는 데 걸리는 기간은 일반적인 경험칙이지 통계가 아니다.
- **법·세무.** 겸업 금지와 종합소득세는 공개 자료 수준의 정보이며 법률·세무 자문이 아니다. 취업규칙 확인과 세무사 상담은 본인이 해야 한다.
- **크몽 규정.** 크몽은 정부지원사업 서류의 대리 작성을 금지한다. 이 계획은 그 범위를 제외한 민간 기업 문서를 대상으로 짰다.

## 1. 조건 정리와 선정 기준

### 1.1 주어진 조건

| 조건             | 해석                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------- |
| 50대 남성 직장인 | 본업이 있다. 겸업 금지 규정과 체력을 고려해 야간·주말 1~2시간으로 끝나야 한다               |
| 하루 1~2시간     | 월 30~60시간. 시급으로 환산하면 매출 300만 원을 위해 **시간당 5만 원 이상**의 일이어야 한다 |
| 월 매출 300만 원 | 순수익이 아니라 매출이다. 수수료와 세금을 빼면 순수익은 230~250만 원 수준이 된다            |
| 영업·마케팅 없음 | 광고, SNS 운영, 전화·방문 영업을 하지 않는다. 수요가 플랫폼을 통해 들어와야 한다            |
| 자본금·재고 없음 | 물건을 사서 파는 일(스마트스토어, 구매대행)과 장비가 필요한 일은 제외                       |
| 클로드 활용      | 글쓰기·분석·구조화 작업에서 클로드가 시간을 줄여 주는 일이어야 한다                         |

### 1.2 선정 기준

시간당 5만 원이라는 기준이 후보를 거의 결정한다. 글 한 편에 1~3만 원을 받는 블로그 원고 대행이나 번역은 클로드로 빨리 써도 시간당 2~3만 원을 넘기 어렵다. 반대로 결과물 한 건이 수십만 원인 일은 월 10건 이내로 끝나므로 시간 조건을 맞출 수 있다. 그래서 **단가가 높고, 플랫폼이 수요를 가져오며, 본인의 직장 경력이 품질 차이를 만드는 일**을 찾았다.

「영업·마케팅 없음」은 엄밀히 말하면 「상품 페이지를 한 번 만들고 리뷰로 신뢰를 쌓는 것까지는 한다」는 뜻으로 읽었다. 이것조차 하지 않으면 플랫폼에서 주문이 오지 않는다. 다만 이 작업은 입점 첫 2주에 집중되고 이후에는 반복되지 않는다.

### 2.2 제외한 것들

- **정부지원사업(예비창업패키지 등) 사업계획서 대행.** 단가가 50~100만 원으로 매력적이지만 크몽이 「정부 지원사업 관련 문서 대리 작성」을 불법 서비스로 규정해 판매를 금지한다. 신청자가 직접 작성해야 하는 공고 규정도 있다. 이 계획에서는 다루지 않는다.
- **스마트스토어·구매대행·중고 리셀.** 재고 또는 선결제 자본이 필요하고 상품 노출을 위한 광고가 사실상 필수다.
- **주식·코인 자동매매, 부동산.** 자본이 필요하고 매출 개념이 아니다.
- **배달·대리운전.** 클로드와 무관하고 50대 체력에 부담이 크다.

### 2.3 왜 ①이 1순위인가

1. **경력이 곧 상품이다.** 제안서를 「써 본」 사람은 많지만 「통과시켜 본」 사람은 적다. 20~30년 직장 생활에서 결재·수주·심사를 거친 경험은 20대 프리랜서가 흉내 낼 수 없고, 구매자(중소기업 대표, 팀장)는 그 점을 상품 페이지에서 바로 알아본다.
2. **클로드가 가장 잘 돕는 일이다.** 구조 잡기, 초안 쓰기, 숫자 표로 정리하기, 문장 교정은 클로드가 10분이면 한다. 사람은 고객 인터뷰, 업계 맥락, 숫자 검증, 최종 어조에 집중하면 된다. 건당 시간이 3분의 1로 줄어 하루 1~2시간 조건이 성립한다.
3. **플랫폼이 영업을 대신한다.** 크몽은 구매자가 「제안서 작성」을 검색해서 판매자를 고른다. 판매자는 광고를 하지 않는다. 리뷰 10개를 넘기면 검색 순위가 안정된다.
4. **②와 ③을 같은 재료로 병행할 수 있다.** 경력기술서 첨삭(②)은 같은 글쓰기 역량으로 비수기를 채우고, 작업하며 쌓인 구조를 템플릿 전자책(③)으로 묶으면 추가 수익이 된다.

## 4. 서비스 구성과 가격

### 4.1 상품 3단계

크몽은 상품 하나에 STANDARD·DELUXE·PREMIUM 세 등급을 두는 구조가 표준이다. 등급은 분량과 포함 범위로 나눈다.

| 등급     | 가격    | 범위                                                                               | 납기 | 수정 | 예상 작업 시간 |
| -------- | ------- | ---------------------------------------------------------------------------------- | ---- | ---- | -------------- |
| STANDARD | 25만 원 | 10쪽 이내 제안서·보고서. 고객 자료 기반 구조 설계 + 초안 + 교정 1회                | 5일  | 1회  | 4시간          |
| DELUXE   | 45만 원 | 20쪽 이내 제안서·사업계획서 + 발표용 요약 슬라이드 10장                            | 7일  | 2회  | 8시간          |

### 4.2 가격 근거

- 숨고 공개 자료 기준 일반 사업계획서 작성 평균 30만 원(10~50만 원)이다. STANDARD 25만 원은 시장 평균보다 약간 낮게 시작해 리뷰를 모으고, 리뷰 10개 이후 30만 원으로 올린다.
- 50대 경력자의 「검토자 관점」을 PREMIUM의 리허설 피드백으로 상품화한다. 이 항목은 젊은 판매자가 제공하기 어려워 가격 방어 요소가 된다.
- 시간당 매출로 환산하면 STANDARD 6.3만 원, DELUXE 5.6만 원, PREMIUM 5.7만 원이다. 1.2절 기준(5만 원)을 모두 넘는다.

### 4.3 상품 페이지에 쓸 차별점 (초안)

- 「`[입력: 업종]`에서 `[입력: N]`년, 제안서 `[입력: N]`건 수주·결재 경험」
- 「심사자가 3분 안에 결론을 찾도록 쓰는 구조」
- 「초안을 48시간 안에 보여 드리고 방향을 맞춘 뒤 완성」

### 5.2 클로드 활용 체계

- **프로젝트 분리.** 클로드 프로젝트를 「제안서 컨설팅」으로 하나 만들고, 4.3절의 차별점·작업 원칙·문체 지침을 프로젝트 지침에 넣어 둔다. 고객별 자료는 대화마다 새로 올린다.
- **고정 프롬프트 5종.** 질문지 생성, 자료 요약, 목차 3안, 섹션 초안, 검토자 모드(「심사위원이 되어 이 문서의 약점 10가지를 찾아라」). 부록 A에 초안이 있다.
- **지키는 선.** 고객 자료는 작업 종료 후 대화에서 삭제한다. 본업 회사 문서는 절대 올리지 않는다. 클로드가 만든 숫자와 사례는 반드시 출처를 확인하거나 고객 자료로 대체한다.

## 부록 A. 클로드 프롬프트 초안 5종

프로젝트 지침에 넣을 공통 원칙:

```
너는 20년 경력의 B2B 제안서 컨설턴트를 돕는 보조자다.
- 고객이 준 자료에 없는 숫자·사례·고객사명을 만들어 내지 않는다. 필요하면 [확인 필요]로 표시한다.
- 심사자가 3분 안에 결론을 찾도록 결론 → 근거 → 상세 순서로 쓴다.
- 한 문단은 3문장 이내, 한 문장은 25자 내외의 짧은 한국어로 쓴다.
- 과장 표현(최고, 유일, 혁신적)을 쓰지 않고 숫자로 말한다.
```

1. **질문지 생성**: 「고객 업종 `[입력]`, 문서 목적 `[입력]`, 분량 `[입력]`쪽이다. 작성에 필요한 정보를 받기 위한 질문지를 15문항 이내로 만들어라. 각 문항에 왜 필요한지 한 줄씩 붙여라.」
2. **자료 요약**: 「첨부한 고객 자료를 ① 핵심 주장 5개, ② 근거 숫자 전부(출처 페이지 포함), ③ 빠져 있어서 고객에게 더 물어야 할 것 순서로 정리해라.」
3. **목차 3안**: 「이 문서를 읽을 사람은 `[입력: 심사자 유형]`이다. 서로 다른 전략의 목차 3안을 만들고 각 안의 장단점과 어떤 고객 상황에 맞는지 비교 표로 보여라.」
4. **섹션 초안**: 「확정한 목차의 `[입력: 섹션명]`을 `[입력]`자 분량으로 써라. 고객 자료의 숫자만 쓰고 없는 것은 [확인 필요]로 남겨라. 표가 더 낫다고 판단되면 표로 바꿔라.」
5. **검토자 모드**: 「너는 이 제안서를 떨어뜨리고 싶은 심사위원이다. 논리 빈틈, 근거 없는 주장, 숫자 불일치, 경쟁사가 반박할 지점을 10가지 찾아 심각한 순서로 나열하고 각각 고칠 방법을 제안해라.」
