# 쉬운 한국어로 코드 설명

설명할 대상: $ARGUMENTS

## 할 일

1. 대상이 비어 있으면 "설명할 파일이나 함수 이름을 알려 주세요"라고만 답한다.
2. 대상을 찾아 읽는다. 함수 이름이면 Grep으로 정의 위치를 찾는다. 찾지 못하면 그렇다고 말한다.
3. 아래 순서로 답한다. 전문 용어는 처음 나올 때 한 번 풀어 쓴다.
   - **한 줄 요약:** 이것이 무엇을 하는지 한 문장.
   - **언제 실행되나:** 누가, 어떤 상황에서 이것을 부르는지.
   - **무엇을 받고 무엇을 내놓나:** 입력과 결과.
   - **주의할 점:** 실패하는 경우나 부작용. 없으면 생략.
4. 코드를 길게 인용하지 않는다. 꼭 필요한 줄만 `파일:줄번호`로 가리킨다.
5. 파일을 수정하지 않는다.
