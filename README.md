# jangha-kim

업무 문서를 모아 두는 한국어 저장소입니다. 코드나 빌드 시스템은 없고, 마크다운 원고와 거기서 만든 Word·PPT 파일이 전부입니다.

## 폴더 구성

```
docs/
├── 사업계획서/
│   ├── 스마트경찰경광등/   사업계획서, 개발계획 과제제안서, 과제제안 PPT
│   ├── 클로드활용투잡/     직장인투잡 사업계획서, 구글활용 추가조사
│   └── 빌드/               Word·PPT 생성 스크립트 (모든 사업 공용)
└── 투잡키트/
    ├── 1-제안서컨설팅/     접수 질문지, 고객응대 템플릿, 크몽 상품 원고, 포트폴리오 샘플
    └── 3-전자책/           전자책 원고, 판매페이지 원고, 등록 절차
```

## 작업 규칙

- 원본은 마크다운(`.md`)입니다. `.docx`와 `.pptx`는 원본에서 만든 결과물이므로 원본을 고친 뒤 다시 만듭니다.
- 재생성 방법은 [`docs/사업계획서/빌드/README.md`](docs/사업계획서/빌드/README.md)에 있습니다.
- 새 사업 문서는 `docs/사업계획서/<사업명>/`에 둡니다.
- 파일 이름은 `YYYY-MM_주제` 형식을 씁니다.
- 문서, 커밋 메시지, PR 설명은 모두 한국어로 씁니다.
